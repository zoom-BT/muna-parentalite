# 🎬 Script de démo — Muna (≈ 2 min)

Objectif : montrer *un cerveau, plusieurs portes* + l'inclusion. Sert aussi de
storyboard pour la vidéo de candidature.

## Préparation
- `npm run dev` (ou l'URL Vercel). Optionnel : `GROQ_API_KEY` dans `.env.local` pour des réponses génératives (sinon repli local, la démo marche quand même).
- Bot lancé (`bot/`) avec un vrai token, `MUNA_API` pointant sur la plateforme.

## Déroulé

| Temps | Écran | À dire |
|---|---|---|
| 0:00 | Accueil | « Le programme national de parentalité positive touche peu de parents. Muna le passe à l'échelle. » |
| 0:15 | Sélecteur de langue → **Pidgin** | « L'app parle la langue des parents : français, anglais, **pidgin**. » |
| 0:25 | Espace parent → clic sur une suggestion | « Un parent demande : *mon enfant fait des colères* → réponse **ancrée sur le programme**, avec la source citée. » |
| 0:45 | Assistant → bouton **🔊 Écouter** | « Et pour les parents qui ne lisent pas, ou non-voyants : la réponse **se lit à voix haute**. » |
| 0:55 | Assistant → taper *« je frappe mon enfant »* | « Si un danger est détecté, Muna **escalade vers le 117** — la protection de l'enfant d'abord. » |
| 1:10 | Apprendre → module 1 → messages + quiz | « Le programme en micro-leçons : messages courts, **audio en fulfulde**, quiz, progression sauvegardée — même **hors ligne**. » |
| 1:35 | Facilitateur → enrôler un parent | « Le facilitateur enrôle et suit les parents sur le terrain : **il en touche 10× plus**. » |
| 1:50 | Tableau de bord | « Et MINPROFF suit la portée en temps réel — ici le pilote **Adamaoua**. » |
| 2:00 | Bot Telegram → une question | « La même intelligence sur **Telegram** — et demain WhatsApp, SMS, IVR. Un cerveau, plusieurs portes. » |

## Message de clôture
« Muna : le programme de parentalité positive, dans la poche de chaque parent — accessible, souverain, inclusif. »
