## Lecture du budget
- **Développement applicatif : 0 FCFA** — le prototype est **déjà construit et déployé** ; le budget porte sur le **déploiement terrain** et le **contenu**.
- **Coûts ponctuels** (contenu, formation, kits, S&E, communication) : ~3 550 000 FCFA — **réutilisables** pour les régions suivantes.
- **Coûts récurrents** (télécom, hébergement/IA, coordination) : ~1 700 000 FCFA sur le pilote ; restent **faibles** après (open-source, free-tier).
- **Coût-efficacité : ~4 375 FCFA par parent touché**, avec une infrastructure réutilisable (coût marginal décroissant à l'échelle).
- **Économies & imprévus** réinvestis dans le contenu et les langues, **sans réduire** l'accessibilité, la qualité ni la sécurité.

*Budget provisionnel, à ajuster selon les orientations des organisateurs. Le prix du concours amorce le financement ; le complément est recherché via la RSE des télécoms, les subventions ONG et l'appui institutionnel MINPROFF/UNICEF.*
