# Plan de travail — Phase pilote · Muna
### Concours d'Innovation « Parentalité Positive » (UNICEF Cameroon × MINPROFF)
Région : **Adamaoua** · Durée : **3 mois** (septembre–novembre 2026)

| Mois | Activités clés | Livrables | Responsable |
|---|---|---|---|
| **Préparation (S0)** | Cadrage avec MINPROFF/UNICEF ; validation des contenus ; sélection des 1-3 communautés | Contenus validés · communautés confirmées | Porteur + référent MINPROFF |
| **Mois 1** | Production de l'audio fulfulde ; recrutement & **formation des facilitateurs** ; finalisation de la version pilote | Version pilote déployée · kit facilitateur · audio prêt | Porteur (tech) · relais terrain |
| **Mois 2** | **Déploiement** dans les communautés ; enrôlement des parents ; activation SMS/IVR ; **enquête « avant »** | ~1 200 parents enrôlés · données de base · canaux actifs | Relais terrain · facilitateurs |
| **Mois 3** | Suivi via tableau de bord ; itérations selon retours ; **enquête « après »** ; bilan | **Rapport d'impact** · recommandations de mise à l'échelle | Porteur · S&E |

## Jalons & points de décision
- **J1 (fin M1)** : version pilote + facilitateurs formés → feu vert déploiement.
- **J2 (fin M2)** : cible d'enrôlement atteinte + données de base collectées.
- **J3 (fin M3)** : rapport d'impact remis aux organisateurs (indicateurs d'usage, d'apprentissage, de comportement).

## Assurance qualité & rapportage
- Tests automatisés (détection de danger, récupération de contenu) ; tests d'utilisabilité avec de vrais parents (dont non-lecteurs).
- Validation éditoriale du contenu par MINPROFF/UNICEF **avant** diffusion.
- Rapportage régulier aux organisateurs, décisions pilotées par les données du tableau de bord et les retours terrain.

## Indicateurs suivis
Utilisation (actifs, sessions) · Achèvement (complétion leçons/quiz) · Satisfaction · Accessibilité (part d'usage audio/vocal) · Apprentissage (score quiz) · Comportement (auto-déclaration avant/après).

**Cibles :** ≥ 60 % de complétion de la 1re leçon · ≥ 70 % de satisfaction · progression mesurable du score d'apprentissage.
